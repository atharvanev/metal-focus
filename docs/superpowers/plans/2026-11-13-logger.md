# Activity Logger (v1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A background Python process that, every 4 s, records the frontmost app, window title, browser domain, idle time, app-switch count and "was there typing / clicking / scrolling in this sample" flags into an encrypted local SQLite database. It honors exclude lists, private windows and an automatic financial-site/app exclusion.

**Architecture:** A pure, fully unit-tested core (config, URL sanitizing, exclusion, sample assembly, the switch counter, the sampler `tick`, the encrypted DB) plus thin macOS adapters (NSWorkspace, Accessibility, Quartz idle timers, `osascript`) behind a `Probes` protocol. The process runs a Cocoa run loop: an NSTimer drives `tick()`, and NSWorkspace notifications feed the switch counter on the same thread. **There is no event tap and no keyboard/mouse hook of any kind.**

**Tech Stack:** uv-managed CPython 3.13, pyobjc (Cocoa, Quartz, ApplicationServices), `sqlcipher3-wheels` (SQLCipher 4.12), `keyring` (macOS Keychain), PyYAML, pytest. All are already in `pyproject.toml`.

**Spec:** `CLAUDE.md`: the "Key definitions", "Feature split", "Architecture" and "Privacy rules" sections, plus "First task" items 1-2.

**Scope:** Scaffold + logger + raw-sample storage only. Windowing, categorizer, auto-labeler, check-ins and HSMM each get their own plan. No MLX here.

## Global Constraints

- Python only through uv: `uv run ...`, `uv add ...`. Never pip/conda/system Python.
- Sample every **4 s** (spec: 3-5 s), configurable in `logger/config.yaml`.
- Store **domain + title** only. Never store the URL path, query string, fragment, userinfo or port.
- **Skip private/incognito windows:** no title and no domain stored for them.
- **Never log** password managers, banking, or work-confidential content. Excluded rows keep only time, idle, switch count and activity flags; every identifying field is NULL.
- **No keylogging, no input monitoring.** The logger never creates a `CGEventTap`, never uses `NSEvent` global monitors, and never requests the Input Monitoring permission. Typing/click/scroll activity comes only from `CGEventSourceSecondsSinceLastEventType` (seconds since the last key press / click / scroll, system-wide, no content, no permission). It is stored as 0/1 "activity in this sample" flags. This replaces the spec's "typing/click/scroll rates": windowing turns the flags into the fraction of active samples per window. (User decision, 2026-11-13.)
- **Financial sites and apps are excluded automatically**, with no setup: a built-in list (`logger/financial.yaml`) of domains, domain keywords, title keywords and app bundle ids. Over-excluding is acceptable; under-excluding is not.
- The DB is SQLCipher-encrypted. The key lives in the macOS Keychain (service `metal-focus`, account `sqlcipher-key`). Nothing leaves the machine.
- A missing macOS permission or a failing adapter **never crashes the logger**: that field is stored as NULL and a warning is logged once.
- Data dir: `~/Library/Application Support/metal-focus/`, DB file `activity.db`. Override with env var `METAL_FOCUS_HOME` (tests use it).
- All timestamps: `ts` = Unix epoch seconds (UTC, float), plus `tz_offset_min` = local UTC offset in minutes at sample time.

## Review Focus

1. **The DB exists but the Keychain key is gone** (Keychain reset, new Mac user): the logger must stop with a clear error and **never mint a new key**. A new key silently makes all past data unreadable. Test lives in Task 2.
2. **Permissions not granted yet** (first run, no Accessibility/Automation): the logger keeps sampling with NULL title / NULL domain. It does not crash or stall. Test lives in Task 4.
6. **A bank you never listed** (a small credit union, a brokerage in Chrome): it is still excluded by the domain/title keywords. Test lives in Task 3.
3. **A private window, or a browser that can't say whether it's private** (Safari exposes no private flag; Automation permission denied): no title or domain stored under the default `unknown_private_policy: drop`. Test lives in Task 3.
4. **Lid closed or machine asleep for an hour:** the next sample must not claim it covers the gap. A `gap` event is recorded, and `dt` falls back to the nominal interval. Test lives in Task 4.
5. **A browser hangs on its AppleScript reply** (beachballing Chrome): the call times out after 1.5 s, the domain is NULL (private status unknown → dropped), and the sampler keeps its cadence. Test lives in Task 5.

### Task 2: Encrypted DB, schema, key management

**Files:**
- Create: `data/schema.sql`, `data/db.py`
- Test: `tests/data/test_db.py`

**Interfaces:**
- Consumes: `common.paths.db_path()`; `logger.sample.Sample` (Task 3; to avoid a cycle, `DbSink.write_sample` takes any object with the `Sample` fields and uses `dataclasses.asdict`)
- Produces:
  - `class KeyStore(Protocol)`: `get() -> str | None`, `set(key: str) -> None`
  - `class KeyringStore(KeyStore)`: uses `keyring` with service `metal-focus`, account `sqlcipher-key`
  - `class KeyMissingError(RuntimeError)`, `class WrongKeyError(RuntimeError)`
  - `get_or_create_key(db_path: Path, store: KeyStore) -> str`: returns the stored key. If there is none **and the db file does not exist**, it generates `secrets.token_hex(32)`, stores it and returns it. If there is none **and the file exists**, it raises `KeyMissingError`.
  - `connect(db_path: Path, key: str) -> sqlcipher3.Connection`: runs `PRAGMA key = "x'<hex>'"`, then `PRAGMA journal_mode=WAL`, then `SELECT count(*) FROM sqlite_master` to validate. It raises `WrongKeyError` on `DatabaseError`. The file mode is set to 0600.
  - `init_schema(conn) -> None` (idempotent; `meta.schema_version = '1'`)
  - `class DbSink`: `__init__(conn)`, `write_sample(sample) -> None`, `write_event(ts: float, kind: str, detail: str | None = None) -> None`. Each call commits.

`data/schema.sql`:
```sql
CREATE TABLE IF NOT EXISTS samples (
  id INTEGER PRIMARY KEY,
  ts REAL NOT NULL, tz_offset_min INTEGER NOT NULL, dt REAL NOT NULL,
  bundle_id TEXT, app_name TEXT, window_title TEXT, domain TEXT,
  private INTEGER, excluded INTEGER NOT NULL, fullscreen INTEGER, locked INTEGER NOT NULL,
  idle_s REAL, app_switches INTEGER NOT NULL,
  key_active INTEGER, click_active INTEGER, scroll_active INTEGER
);
CREATE INDEX IF NOT EXISTS samples_ts ON samples(ts);
CREATE TABLE IF NOT EXISTS events (
  id INTEGER PRIMARY KEY, ts REAL NOT NULL,
  kind TEXT NOT NULL CHECK (kind IN ('logger_start','logger_stop','sleep','wake',
        'screens_sleep','screens_wake','lock','unlock','gap','permission_missing')),
  detail TEXT
);
CREATE TABLE IF NOT EXISTS meta (key TEXT PRIMARY KEY, value TEXT NOT NULL);
```
`private`: 1 / 0 / NULL (unknown or not a browser). `key_active/click_active/scroll_active`: 1 if at least one key press / click / scroll happened during this sample's `dt`, 0 if none, NULL if the probe failed. Nothing about *which* key or *where* is ever available to the logger.

### Task 3: Privacy rules + sample assembly

**Files:**
- Create: `logger/privacy.py`, `logger/sample.py`
- Test: `tests/logger/test_privacy.py`, `tests/logger/test_sample.py`

**Interfaces:**
- Consumes: `LoggerConfig`
- Produces:
  - `sanitize_url(url: str | None) -> str | None`: only `http`/`https` URLs give a domain: the lowercase host, with the leading `www.` stripped and no port or userinfo. Anything else (`file:`, `about:`, `chrome:`, unparsable, `None`) gives `None`.
  - `domain_matches(domain: str, suffix: str) -> bool`: an exact or dot-boundary suffix match (`secure.chase.com` matches `chase.com`; `notchase.com` does not).
  - `is_excluded(bundle_id: str | None, domain: str | None, title: str | None, cfg: LoggerConfig) -> bool`: true if the bundle id is listed, the domain suffix-matches `exclude_domains`, the domain contains any `exclude_domain_keywords`, or the title matches `exclude_title_patterns` (the financial title keywords are compiled into whole-word patterns there).
  - Dataclasses (frozen): `AppInfo(bundle_id: str | None, name: str | None, pid: int)`, `WindowInfo(title: str | None, fullscreen: bool | None)`, `BrowserInfo(url: str | None, private: bool | None)`, `InputRecency(key_s: float | None, click_s: float | None, scroll_s: float | None)` (seconds since the last event of each type), and `Sample` with exactly the `samples` columns minus `id`.
  - `build_sample(*, ts: float, tz_offset_min: int, dt: float, app: AppInfo | None, window: WindowInfo | None, browser: BrowserInfo | None, idle_s: float | None, recency: InputRecency | None, locked: bool, app_switches: int, cfg: LoggerConfig) -> Sample`. Each `x_active = int(x_s < dt)`, or NULL when that value (or `recency`) is None.

`build_sample` rules, applied in this order:
1. `locked` → every app/title/domain/private/fullscreen field is NULL, `locked=1`.
2. `domain = sanitize_url(browser.url)` when there's a browser.
3. If `is_excluded(...)` → `bundle_id, app_name, window_title, domain, private` are all NULL, `excluded=1`. Activity flags, switches and idle are kept.
4. When the app is a browser (`bundle_id in cfg.browsers`): if `private is True`, or (`private is None` and the policy is `drop`), then `window_title = domain = NULL`. `private` is stored as given.
5. A non-browser app has `private = NULL` and `domain = NULL`.

### Task 4: Counters + sampler tick

**Files:**
- Create: `logger/counters.py`, `logger/sampler.py`
- Test: `tests/logger/test_counters.py`, `tests/logger/test_sampler.py`

**Interfaces:**
- Consumes: `build_sample`, the `AppInfo/WindowInfo/BrowserInfo/InputRecency/Sample` dataclasses, `LoggerConfig`, and `DbSink`'s method shapes
- Produces:
  - `SwitchCounter`: `on_app_switch()` and `snapshot_and_reset() -> int`. Uses a `threading.Lock`.
  - `class Probes(Protocol)`: `frontmost() -> AppInfo | None`, `window(pid: int) -> WindowInfo | None`, `browser(bundle_id: str) -> BrowserInfo | None`, `idle_seconds() -> float | None`, `input_recency() -> InputRecency | None`, `screen_locked() -> bool`
  - `class SampleSink(Protocol)`: `write_sample(sample: Sample) -> None`, `write_event(ts: float, kind: str, detail: str | None = None) -> None`
  - `Sampler(probes: Probes, switches: SwitchCounter, sink: SampleSink, cfg: LoggerConfig, clock: Callable[[], float] = time.time, tz_offset: Callable[[], int] = <local offset minutes>)` with `tick() -> Sample`

`tick()` semantics:
- `now = clock()`. On the first tick, `dt = cfg.sample_interval_s`. Otherwise `elapsed = now - last`. If `elapsed > cfg.max_gap_s`, it calls `sink.write_event(last, "gap", f"{elapsed:.1f}s")` and sets `dt = cfg.sample_interval_s`; otherwise `dt = elapsed`.
- It calls the probes in the order frontmost → window(pid) → browser(bundle_id), the last **only if** `bundle_id in cfg.browsers`, then idle → input_recency → screen_locked. Each probe is wrapped: any exception means that probe's result is `None` (`screen_locked` → `False`), and a warning is logged **once per probe name** through `logging.getLogger("logger")`.
- When the screen is locked, it skips the window and browser probes.
- It builds the sample, writes it, and returns it.

### Task 5: Browser adapter (AppleScript)

**Files:**
- Create: `logger/macos/browser.py`
- Test: `tests/logger/test_browser.py`

**Interfaces:**
- Consumes: `BrowserInfo`, `LoggerConfig.browsers`, `LoggerConfig.browser_timeout_s`
- Produces:
  - `script_for(kind: str, bundle_id: str) -> str`
  - `parse_reply(kind: str, stdout: str) -> BrowserInfo`
  - `query_browser(bundle_id: str, kind: str, timeout_s: float, run: Callable[..., subprocess.CompletedProcess] = subprocess.run) -> BrowserInfo | None`. It runs `["osascript", "-e", script]` with `capture_output=True, text=True, timeout=timeout_s`. On `TimeoutExpired`, a nonzero exit, or `OSError` it returns `None`.

Scripts. Address the app by `application id "<bundle_id>"`, which is safe because the sampler only calls this when the browser is frontmost, so it is already running. Each returns two lines: URL, then the private flag.
- `chromium`: `tell application id "<bid>" to return (URL of active tab of front window) & linefeed & (mode of front window)`. `mode` is `"incognito"` → `private=True`, `"normal"` → `False`, anything else → `None`.
- `arc`: `tell application id "<bid>" to return (URL of active tab of front window) & linefeed & (incognito of front window as text)`. `"true"`/`"false"` → bool, anything else → `None`.
- `safari`: `tell application id "<bid>" to return URL of current tab of front window`. `private` is always `None` (Safari exposes no private-window flag), so under the default `drop` policy Safari titles and domains are not stored.

- Financial sites and apps are excluded automatically. Optionally add anything the built-in list misses, plus your **IBM repo/project title patterns**, to `logger/config.local.yaml` (`ibm.com` domains are excluded by default).
